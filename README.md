# MSE Autopilot —— 微课课堂练习自动作答（Tampermonkey 用户脚本）

在 MSE 微课平台上自动完成「课堂练习」：**取题 → DeepSeek 作答 → 结构校验 → 填写 → 交卷 → 回读判分 → 下一节**，整单元无人值守。

> 仅供个人学习与自动化技术研究使用。使用前请确认符合所在平台的服务条款。

## 它能做什么

- 从平台接口直接取题目（含阅读原文、选项、词库），不依赖页面 DOM 解析
- 调用 DeepSeek（`deepseek-chat`）生成答案，按题型分别约束（单选字母 / 填空必须逐字取自词库 / 翻译题按方向换语种）
- 选词填空按「题组」整体求解：把 HTML 里的每个填空控件替换成 `[__1__]…[__n__]` 锚点后一次问完，避免空位错位
- 交卷前做结构校验（题数、字母范围、填空值是否在词库）；字数不达标只告警，仍然交卷
- 交卷后回读判分结果（对 / 错 / 未判），据此决定是否重做
- 整单元连跑：按目录树建队列，逐节执行并自动跳下一节

## 安装

1. 浏览器（Edge / Chrome）安装 **Tampermonkey** 扩展
2. 打开 `src/mse-autopilot.s3.user.js`，全选复制
3. Tampermonkey 面板 →「添加新脚本」→ 粘贴覆盖 → `Ctrl+S` 保存
4. 打开课程页，右上角出现浮动面板

## 使用

1. 面板第一个输入框粘贴 **DeepSeek API Key** → 点「保存」（只存本机，见下）
2. 模式保持「AI 作答（智能）」
3. 点「**开始整单元**」，脚本会从当前节起按单元队列逐节执行
4. 想先小范围验证：点「运行单节（交卷）」；只想看不想交：点「只求答案（不交卷）」

可调参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| 节间间隔 | 0 秒 | 两节之间的等待，填多少就等多少（0 = 不等） |
| 已交卷的节 | 重做错题+主观题 | 三档：重做错题+主观题 / 仅重做错题 / 仅重做主观题 |
| 重做阈值 | 2 条 | 需要重做的题数达到该值才重做，否则保留原成绩 |

## API Key 的存放与安全

- Key 通过 Tampermonkey 的 `GM_setValue` 存进**浏览器扩展自己的存储**（本机磁盘，明文），不写入源码、不写 cookie、不发往课程网站
- 输入框保存后立即清空，日志里从不打印 Key
- 所有 AI 请求经 `GM_xmlhttpRequest` 发出，受 `@connect api.deepseek.com` 白名单限制，不会发到其他域名
- 清除方式：Tampermonkey 面板 →「存储 / Storage」→ 删除 `mse_ap_key`
- 建议：在 DeepSeek 控制台单独创建一个 Key 并设置消费额度上限

## 已知限制

- **交卷不可逆**：平台对已交卷的节拒绝再次提交；脚本的「重做」实为「删除旧作答记录后重新提交」，旧成绩会一并作废
- **主观题无法验证**：服务端不自动批改，判分字段为空，只能保证内容非空且切题
- **填空题依赖词库逐字匹配**：大小写、词形不符会被判错
- 站点若修改接口或域名，脚本需要同步调整 `@match` 与接口路径
